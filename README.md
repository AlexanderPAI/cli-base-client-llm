# cli-base-client-llm
Самостоятельное изучение. CLI-клиент для LLM с измерением запросов. Неделя 1

## Цель

Создать консольную программу на Python, которая:

- принимает вопрос пользователя;
- отправляет его облачной языковой модели;
- получает структурированный ответ;
- корректно обрабатывает типичные ошибки;
- записывает технические метрики;
- не хранит секреты в репозитории.

Работай без агентных фреймворков. На этой неделе задача — понять обычный вызов LLM API. Агентный цикл появится позже.

## Ограничения

- Язык: Python 3.11 или новее.
- Один облачный LLM API на выбор.
- Для настроек используй переменные окружения.
- Для структуры ответа используй Pydantic.
- Не добавляй базу данных, веб-интерфейс, RAG или инструменты агента.
- Не записывай полный пользовательский текст в технический журнал без необходимости.
